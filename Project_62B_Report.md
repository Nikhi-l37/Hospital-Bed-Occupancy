# Project 62(B): Smart Hospital Medicine Recommendation System

## Problem Statement

In modern healthcare facilities, hospitals face significant challenges in efficiently matching patient symptoms to appropriate treatments. Key issues include:

- **Manual prescription interpretation** – Doctors write prescriptions on paper, which can be misread or lost.
- **Delayed symptom assessment** – Patients wait for long periods before receiving preliminary treatment suggestions.
- **Lack of digital record** – Paper prescriptions are difficult to digitize and store in hospital management systems.
- **Human error in medicine mapping** – Incorrectly mapping symptoms to medicines can lead to adverse drug reactions.

Traditional hospital systems rely entirely on manual processes for reading prescriptions and recommending medicines. This project builds an **intelligent, AI-powered Smart Hospital Medicine Recommendation System** that uses OCR (Optical Character Recognition), NLP (Natural Language Processing), and a knowledge-based recommendation engine to automate the process of prescription scanning, symptom analysis, and treatment visualization.

---

## Objectives

- Recognize medicine names and text from prescription images using OCR.
- Analyze patient symptom descriptions using NLP keyword extraction.
- Recommend appropriate medicines with dosage schedules using a knowledge-based engine.
- Visualize treatment plans in a clean, card-based Patient Dashboard.
- Build a full-stack web application with React (frontend) and FastAPI (backend).

## Modules

### Module 1: OCR + Medicine Image Classifier (Vision System)

This module accepts a prescription image uploaded by the user and extracts all readable text from it using Optical Character Recognition.

**Libraries Used:**

- `easyocr` – Deep learning based OCR engine supporting 80+ languages
- `opencv-python` – Image decoding and preprocessing
- `numpy` – Image byte array conversion

**How It Works:**

1. User uploads a prescription image (JPG, PNG, WEBP) via the frontend.
2. The image is sent to the backend endpoint `POST /upload-prescription` as `multipart/form-data`.
3. The image bytes are decoded into a NumPy array using OpenCV's `imdecode()`.
4. EasyOCR's `readtext()` function processes the image and extracts all text segments.
5. The extracted text is returned as a JSON array.

**API Endpoint:**

```
POST /upload-prescription
Content-Type: multipart/form-data
Body: file (UploadFile)
```

**Response Format:**

```json
{
  "extracted_text": ["Paracetamol 500mg", "Take twice daily", "Dr. Sharma"]
}
```

**EasyOCR Initialization:**

```python
ocr_reader = easyocr.Reader(['en'])
```

The reader is initialized once at server startup to avoid reloading the deep learning model on every request, ensuring fast response times.

### Module 2: NLP Symptom Description Analyzer

This module analyzes free-text symptom descriptions provided by the patient and extracts known medical keywords using Natural Language Processing techniques.

**Approach:**

- The patient enters a description of their symptoms in plain English.
- The text is converted to lowercase for case-insensitive matching.
- **Regex word-boundary matching** (`\b` pattern) is used to accurately detect symptom keywords without partial matches (e.g., "cold" won't match "scaffold").

**NLP Logic:**

```python
for keyword, treatment in MEDICINE_DB.items():
    if re.search(r'\b' + re.escape(keyword) + r'\b', text):
        detected_symptoms.append(keyword)
```

**API Endpoint:**

```
POST /analyze-symptoms
Content-Type: application/json
Body: {"patient_text": "I have fever and headache since yesterday"}
```

**Request Validation:**

A Pydantic `BaseModel` is used for input validation:

```python
class SymptomRequest(BaseModel):
    patient_text: str
```

| 5 | cold | Respiratory |

### Module 4: Treatment Visualization Dashboard

This module provides a rich visual representation of the treatment recommendations using a card-based layout with icons.

**UI Components:**

- **Symptom Pills** – Detected symptoms displayed as colored badge pills at the top.
- **Recommendation Cards** – Each card contains:
  - 💊 **Pill icon** – Medicine name and dosage
  - 🕐 **Clock icon** – Dosage schedule/timeline
- **Icons Used** (from `lucide-react`):
  - `Pill` – Represents medicine
  - `Clock` – Represents dosage timeline
  - `Activity` – Represents detected symptoms
  - `Sparkles` – Section header decoration

**Card Layout:**

- Cards are rendered in a responsive CSS Grid (`auto-fill, minmax(300px, 1fr)`).
- Each card has a gradient header showing the symptom name in uppercase.
- Hover effects with elevation animation (`translateY(-3px)` + box-shadow).
